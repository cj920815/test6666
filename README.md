# 科技知识导航网站

一个具有科技风格的链接导航网站，支持管理员编辑和用户浏览功能。

## 功能特点

- **管理员功能**：
  - 链接添加/删除/编辑
  - 分类管理
  - 控制链接显示/隐藏

- **用户功能**：
  - 按分类浏览链接
  - 查看链接点击数
  - 确认对话框交互

- **设计风格**：
  - 科技风格界面
  - 动态粒子效果
  - 响应式设计，适配移动设备

## 使用说明

### 管理员登录

1. 点击页面右上角的"管理员登录"按钮
2. 输入默认用户名和密码：
   - 用户名：`admin`
   - 密码：`admin123`

### 管理链接

登录后，您可以：

1. **添加链接**：点击"添加新链接"按钮，填写链接信息
2. **编辑链接**：点击链接旁边的编辑图标
3. **切换显示/隐藏**：点击眼睛图标可以控制链接是否在前台显示
4. **删除链接**：点击垃圾桶图标可以删除链接

### 用户浏览

1. 用户可以通过顶部的分类按钮筛选不同类别的链接
2. 点击链接时会弹出确认对话框，点击"好"后才会跳转到目标网站
3. 每次点击都会增加链接的浏览量计数

## 技术实现

- 纯前端实现，无需后端服务器
- 使用 localStorage 存储链接数据
- 响应式设计，适配各种设备尺寸

## 自定义配置

如需修改默认管理员账号，请编辑 `script.js` 文件中的以下内容：

```javascript
// Admin credentials
const ADMIN_USERNAME = 'admin';
const ADMIN_PASSWORD = 'admin123';
```

## 部署方法

1. 将所有文件上传到您的网站服务器
2. 无需额外配置，直接访问 index.html 即可使用

## 注意事项

- 本项目使用 localStorage 存储数据，清除浏览器缓存会导致数据丢失
- 在实际生产环境中，建议实现后端存储和真实的用户认证系统
